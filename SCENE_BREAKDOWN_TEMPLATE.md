## Escena 01 — Nombre interno descriptivo

**Identificador estable:** `SC-01`

- **Función narrativa:** ¿Por qué existe esta escena? ¿Qué debe comprender o sentir el espectador?
- **Fragmento exacto del guion:** copiar aquí las primeras y últimas palabras, o el párrafo exacto que acompaña a esta escena. No reescribirlo.
- **Intención emocional:** emoción, tensión o atmósfera buscada.
- **Imagen principal:** describir qué aparece, sujeto, entorno, época y acción.
- **Recursos utilizados:** ruta exacta de cada archivo, por ejemplo `assets/scene-01-main.webp`.
- **Origen del recurso:** generado / fotografía propia / archivo / fuente externa; añadir referencia o licencia cuando corresponda.
- **Composición:** plano, perspectiva, posición del sujeto, profundidad, espacio negativo y elementos de primer/segundo plano.
- **Color e iluminación:** paleta, temperatura, contraste, sombras y dirección de luz.
- **Movimiento:** zoom, travelling, parallax, movimiento de elementos, velocidad y trayectoria.
- **Transición de entrada:** cómo aparece desde la escena anterior.
- **Transición de salida:** cómo prepara la siguiente escena.
- **Duración estimada:** segundos.
- **Relación con el audio externo:** cómo debe acompañar la voz; indicar pausas o énfasis útiles sin modificar el guion.
- **Elementos que no deben cambiar:** rasgos visuales, encuadre, objeto, época, continuidad u otros detalles.
- **Criterios de aceptación:** qué debe verse y funcionar para considerar correcta la escena.

Repetir el bloque completo para cada escena.

## Reglas de edición por escena

- El identificador `SC-XX` es permanente aunque cambie el orden o el nombre interno.
- Cuando el usuario diga “en la escena 3 cambia…”, identificar la escena por el ID y confirmar el alcance usando este documento.
- No modificar escenas no relacionadas.
- Si un cambio afecta continuidad, transición, guion o escenas vecinas, explicarlo antes de aplicar.
- Actualizar este documento cada vez que cambie una escena, sus recursos, el fragmento narrativo o su duración.
- Mantener el guion TTS en su archivo separado; este documento solo contiene fragmentos de referencia para edición y sincronización.
- La web no debe renderizar este documento ni sus anotaciones.
